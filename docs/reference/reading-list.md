# Reading list

This list is for readers who want to go deeper. It is divided into the
theoretical sources used in this documentation, the standards the architecture
relies on, and practical reading for agent systems.

## Theoretical sources

The [research map](../theory/research-map.md) lists the Huiwen Han works cited in
the theory section, with DOIs and notes on where each is used. Start there for:

- Unified Agent Dynamics (UAD)
- DIKCA and *Architecture as Law*
- Intent-Conditioned Computation and Agent-Oriented Programming
- Probabilistic Program Execution Semantics (PPES)
- AVDM, ARCM, PACT, and AADM
- The economics and security papers

The author profiles are the best way to see the current list:

- [ORCID](https://orcid.org/0009-0000-5852-5916)
- [ResearchID](https://researchid.co/hanhuiwen)
- [Google Scholar](https://scholar.google.com/citations?user=7Hrh5dkAAAAJ)

## Standards and protocols

See [Standards and protocols](standards.md) for the full list with links. The
short version:

- **MCP** for tool/context integration.
- **OpenAPI** and **JSON Schema** for contracts.
- **OIDC**, **OAuth 2.0**, and **SPIFFE** for identity.
- **OpenTelemetry** for telemetry.
- **SLSA**, **CycloneDX**, and **SBOM** practices for supply chain.
- **ISO/IEC/IEEE 42010**, **TOGAF**, and **ArchiMate** for architecture practice.
- **NIST AI RMF** and **OWASP LLM Top 10** for risk and security framing.

## A note on citations

Some theoretical works are preprints or working papers. Check the DOI record for
the current status. When citing this documentation, cite the repository and the
relevant source paper; do not present the synthesis as the original work.
