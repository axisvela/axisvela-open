# Documentation roadmap

[English](roadmap.md) | [中文](../zh/reference/roadmap.md)

This is the roadmap for the **documentation and project index**, not for the
products. Product roadmaps live in their own repositories.

## Near term

- Keep product pages aligned with the authoritative repositories.
- Add more diagrams for the end-to-end practice guides.
- Improve cross-linking between theory, architecture, and practice.
- Keep the Chinese and English sections in sync.
- Track the pkg.go.dev indexing status of the lowercase
  `limenora-open` module.

## Mid term

- Add worked examples for identity, authorization, and evidence flows.
- Add a side-by-side comparison of the open surfaces and their boundaries.
- Add more source notes for the theoretical pages where claims are easy to
  misread.
- Review the `harmovela` and `harmovela-open` boundary and document it clearly.

## Long term

- A `projects.yaml` schema v2 if the index needs new fields.
- Generated indexes from the product repositories to reduce drift.
- More translations if there is demand.
- A stable 1.0 documentation contract.

## How to suggest a change

Open an issue on the repository with the page, the problem, and the proposed
change. For product changes, use the product repository instead. See
[Contributing](https://github.com/axisvela/axisvela-open/blob/main/CONTRIBUTING.md).
