# Harmovela Open

**Repository:** [axisvela/harmovela-open](https://github.com/axisvela/harmovela-open) ·
**License:** Apache-2.0 · **Language:** JavaScript · **Layer:** Foundation (companion)

> The public examples and ecosystem hub for the Harmovela protocol.

## The problem

A protocol specification is necessary but not sufficient. Integrators need
runnable examples, a registry of implementations and tools, and practical
guidance for contributing a new adapter or transport.

## What it provides

- Runnable integrations that show the coordination dimensions working together.
- An ecosystem registry of SDKs, runtimes, transports, adapters, and tools.
- Authoring guides for examples, registry entries, and contributions.
- Repository validation tooling and issue/PR templates.

## Why it matters

- **Discovery.** A single registry makes the protocol ecosystem visible.
- **Contribution path.** The examples and guides lower the cost of adding an
  integration.
- **Separation of concerns.** The protocol repository remains the source of
  truth for specifications and conformance.

## How it fits

Harmovela Open is a companion to [Harmovela](harmovela.md). It is not a separate
protocol implementation; it is the public working surface around the protocol.
