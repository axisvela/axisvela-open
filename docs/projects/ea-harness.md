# ea-harness

**Repository:** [axisvela/ea-harness](https://github.com/axisvela/ea-harness) ·
**License:** MIT · **Language:** Python · **Layer:** Related

> An earlier public architecture design and validation skill pack for AI coding
> assistants, maintained separately from TAXOVELA.

## The problem

Architecture work with AI assistants needs structure: requirements, design,
diagram validation, an enforcement gate, and a workflow gatekeeper. The public
`ea-harness` repository explored that problem as an installable skill pack and
CLI.

## What it provides

- Enterprise-architecture skills and a CLI for Claude Code, OpenCode, Codex,
  GitHub Copilot, and Cursor.
- Requirements, design, diagram validation, enforcement, and workflow
  gatekeeping.
- A multi-project workspace.
- A pip-installable package and a Claude Code plugin marketplace.

## Why it matters

- **Historical context.** It is one of the earlier public artifacts of the
  architecture practice that TAXOVELA now develops.
- **Separate project.** It remains a distinct repository with its own release
  and evolution.

## How it fits

`ea-harness` is related to [TAXOVELA](taxovela.md), the current AI-native
architecture project in this map. The two are maintained separately; this page
does not claim that one replaces the other.
