# GNOSIVELA

**Repository:** [axisvela/gnosivela-open](https://github.com/axisvela/gnosivela-open) ·
**License:** Apache-2.0 · **Language:** Go · **Layer:** Trust and knowledge

> A semantic and knowledge fabric: govern concepts, entities, claims, evidence,
> and conflicts, then project scoped grounding views.

## The problem

Retrieval-Augmented Generation often stops at “find similar chunks.” Enterprises
need something stronger: agreed definitions, stable entity identity, claims
backed by evidence, explicit conflict handling, and views scoped to a purpose,
tenant, or decision.

Without that, agents get plausible context with no provenance.

## What it provides

- Concept and ontology definitions.
- Entity resolution and stable references.
- Evidence-backed assertions.
- Conflict governance.
- Purpose-scoped grounding views for agents, planners, twins, and applications.
- SDKs, an API contract, and a reference ontology.

## Why it matters

- **Grounded, not just retrieved.** Context carries definitions and evidence.
- **Conflicts are visible.** Disagreement is governed rather than averaged away.
- **Scoped views.** Different consumers can see the knowledge appropriate to
  their purpose.

## How it fits

GNOSIVELA fills the retrieval and knowledge seam in
[PRAXO-CORE](praxo-core.md). It grounds [ONTOVELA](ontovela.md) world models,
[ORCHADYN](orchadyn.md) plans, and agent context in
[MNEMOVELA](mnemovela.md).
