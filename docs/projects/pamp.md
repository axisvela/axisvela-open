# PAMP

**Repository:** [axisvela/AXISRobo-PAMP](https://github.com/axisvela/AXISRobo-PAMP) ·
**License:** See repository · **Language:** Python · **Layer:** Adjacent

> A practical platform for enterprise architecture management.

## The problem

Architecture work needs a home: a portfolio of capabilities, applications,
standards, and roadmaps that people can actually maintain. Diagrams alone do not
provide that home.

PAMP is a management platform for the architecture portfolio, adjacent to the
design-and-validation workflow in TAXOVELA.

## What it provides

The repository describes a practical enterprise-architecture management
platform. Its topics reference established architecture frameworks and
practices, including TOGAF and ArchiMate.

## Why it matters

- **Portfolio view.** Architecture management is broader than one design.
- **Practical tooling.** The project is oriented toward day-to-day architecture
  management rather than a theoretical model.
- **Complements design validation.** PAMP manages the portfolio; TAXOVELA
  validates individual designs.

## How it fits

PAMP is adjacent to [TAXOVELA](taxovela.md). It is not a runtime component and
does not participate in agent execution.

The repository still carries the historical `AXISRobo-PAMP` name. Check the
repository for the current license and roadmap.
