# 世界模型与数字孪生

[English](../../concepts/world-models.md) | 中文

Agent 推理企业问题时不只需要检索文本。它需要关于**存在什么**、**什么是真的**、
**什么变了**以及**什么证据支持**的模型。

## 运营世界模型

运营世界模型是决策相关状态的共享表示：资产、订单、设施、任务、人员、策略及其关系。
它不是仪表盘，也不是数据湖。它是能回答问题的模型。

## 数字孪生

数字孪生是特定系统——工厂、车队、供应链——的世界模型，通过断言与观测与真实系统保持同步。
孪生只有在**时间性**和**证据性**时才有用：

- **双时间：** 区分何时为真与系统何时记录；
- **证据性：** 每个断言指向来源与置信度。

项目：[ONTOVELA](../projects/ontovela.md)。

## 概念与知识锚定

世界模型需要一致定义。没有定义，“客户”“站点”“活跃”在不同系统中含义不同。语义层定义
概念、解析实体、用证据支持主张并治理冲突。

项目：[GNOSIVELA](../projects/gnosivela.md)。

## 可能世界

世界模型描述现在是什么。仿真探索可能是什么。受治理实验定义世界、场景、扰动、控制与种子，
产生可比较、可验证的证据。

项目：[PEIRAVELA](../projects/peiravela.md)。

## 为什么对 Agent 重要

- **共享上下文。** Agent、规划器和人基于同一状态推理。
- **有据可依的决策。** 主张带证据，而不是自信的散文。
- **安全实验。** 高风险变更可以先在可能世界中测试。
- **可审计性。** 信念历史是记录的一部分。

## 一个提醒

世界模型的好坏取决于摄取与治理。一个静默接受所有断言的孪生只是昂贵的仪表盘。证据、冲突
处理与新鲜度不是可选项。
