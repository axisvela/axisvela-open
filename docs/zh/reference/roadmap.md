# 文档路线图

[English](../../reference/roadmap.md) | 中文

这是**文档与项目索引**的路线图，不是产品的路线图。产品路线图在各自仓库。

## 近期

2026-11-08 地图更新将 AKROVELA 与 DIDACTOVELA 标为未发布 0.1.0 初始化骨架，不是已交付执行或
学习集成。状态、规划关系虚线、许可区分和中英文页面应与所属仓库同步；不得把已有网关、边缘推理
或证据 spool 改写为已迁移实现。功能交付计划仍归产品，本路线图只跟踪文档。

- 保持产品页与权威仓库一致。
- 为端到端实操指南补充更多图。
- 加强理论、架构与实操之间的交叉链接。
- 保持中英文部分同步。
- 跟踪小写 `limenora-open` 模块的 pkg.go.dev 索引状态。

## 中期

- 增加身份、授权与证据流程的完整示例。
- 增加开放接口层及其边界的并排对比。
- 为容易误读的理论页补充更多来源说明。
- 复审并清楚记录 `harmovela` 与 `harmovela-open` 的边界。

## 长期

- 如果索引需要新字段，推出 `projects.yaml` schema v2。
- 从产品仓库生成索引，减少漂移。
- 有需求时增加更多翻译。
- 形成稳定的 1.0 文档契约。

## 如何提出变更

在仓库开 issue，说明页面、问题与建议变更。产品变更请使用产品仓库。见
[贡献指南](https://github.com/axisvela/axisvela-open/blob/main/CONTRIBUTING.md)。
