# ea-harness

[English](../../projects/ea-harness.md) | 中文


**仓库：** [axisvela/ea-harness](https://github.com/axisvela/ea-harness) ·
**许可证：** MIT · **语言：** Python · **层次：** 相关

> 早期面向 AI 编程助手的架构设计与验证技能包，与 TAXOVELA 独立维护。

## 问题

用 AI 助手做架构需要结构：需求、设计、图验证、执行门禁与工作流门禁。公开的
`ea-harness` 仓库以可安装技能包与 CLI 探索了这个问题。

## 提供什么

- 面向 Claude Code、OpenCode、Codex、GitHub Copilot、Cursor 的企业架构技能与 CLI。
- 需求、设计、图验证、执行与工作流门禁。
- 多项目工作区。
- 可 pip 安装的包与 Claude Code 插件市场。

## 为什么重要

- **历史背景。** 它是 TAXOVELA 当前继续发展的架构实践较早的公开产物之一。
- **独立项目。** 它仍是拥有自己发布与演进的独立仓库。

## 如何衔接

`ea-harness` 与 [TAXOVELA](taxovela.md) 相关，后者是本地图中的当前 AI 原生架构项目。
两者独立维护；本页不声称一个替代另一个。
