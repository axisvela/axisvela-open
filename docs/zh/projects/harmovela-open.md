# Harmovela Open

[English](../../projects/harmovela-open.md) | 中文


**仓库：** [axisvela/harmovela-open](https://github.com/axisvela/harmovela-open) ·
**许可证：** Apache-2.0 · **语言：** JavaScript · **层次：** 基础层（配套）

> Harmovela 协议的公开示例与生态中心。

## 问题

协议规范必要但不充分。集成者需要可运行示例、实现与工具目录，以及贡献新适配器或传输的
实用指南。

## 提供什么

- 展示协调维度如何协同工作的可运行集成。
- SDK、运行时、传输、适配器与工具的生态注册表。
- 示例、注册表条目与贡献的编写指南。
- 仓库校验工具与 issue/PR 模板。

## 为什么重要

- **发现。** 一个注册表让协议生态可见。
- **贡献路径。** 示例与指南降低添加集成的成本。
- **关注点分离。** 协议仓库仍是规范与一致性的最终来源。

## 如何衔接

Harmovela Open 是 [Harmovela](harmovela.md) 的配套。它不是独立协议实现，而是协议周围的
公开工作界面。
