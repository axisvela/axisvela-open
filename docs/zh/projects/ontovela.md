# ONTOVELA

> 有证据、双时间的运营世界模型与数字孪生。

## 问题

仪表盘显示快照。决策需要更多：现在什么是真的、当时什么是真的、何时变化、什么证据支持
主张。运营状态通常散落在各系统中，没有共享、可审计的模型。

ONTOVELA 提供共享世界模型，让 Agent、规划器与人可以推理，而不假装最新一行就是全部真相。

## 提供什么

- 租户范围的运营世界模型。
- 有证据支持的断言。
- 双时间状态：有效时间与记录时间。
- 孪生状态、快照与变更历史。
- HTTP API 与 SDK。
- 可被规划器、Agent 与仿真消费的模型。

## 为什么重要

- **时间感知真相。** “我们当时相信什么、何时相信”可回答。
- **证据附着。** 状态不只是值，它有溯源。
- **共享上下文。** 多系统基于同一模型推理，而不是协调分叉副本。

## 如何衔接

ONTOVELA 消费 [GNOSIVELA](gnosivela.md) 的概念与证据，为
[ORCHADYN](orchadyn.md)、[PEIRAVELA](peiravela.md)、[TEKMOVELA](tekmovela.md) 与
[KINETOVELA](kinetovela.md) 提供运营上下文。

公开仓库是开发者平台接口；当前许可证与可用性见仓库。
