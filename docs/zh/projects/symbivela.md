# SYMBIVELA

[English](../../projects/symbivela.md) | 中文


**仓库：** [axisvela/symbivela-open](https://github.com/axisvela/symbivela-open) ·
**许可证：** Apache-2.0 · **语言：** Go · **层次：** 人类与物理操作

> 人机协作工作台：目标、计划评审、审批、异常、干预、结果与证据。

## 问题

“Human in the loop”常意味着一个通知加一个是/否按钮。真正的监督需要上下文：目标是什么、
机器计划什么、改了什么、风险是什么、谁负责决定、之后发生了什么。

SYMBIVELA 把人类监督变成一等工作台，而不是弹窗。

## 提供什么

- 目标设定与共享上下文。
- 执行前计划评审。
- 高风险行动审批。
- 异常队列与干预。
- 人与 Agent 之间的交接。
- 结果接受与证据检查。
- Web API 与协作前端。

## 为什么重要

- **人类主权。** 人可以在不管理每一步的情况下干预。
- **可问责决定。** 审批与干预被记录。
- **异常是常态。** 工作台为不按快乐路径发展的案例设计。

## 如何衔接

SYMBIVELA 是 [RHEOVELA](rheovela.md) 流程、[MODUREGIS](moduregis.md) 能力与
[PRAXOVELA](praxovela.md) Agent 运行的人类控制层。它消费
[TEKMOVELA](tekmovela.md) 证据与 [AEGIVELA](aegivela.md) 身份。
